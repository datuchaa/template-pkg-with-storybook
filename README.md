# 🧪 JavaScript Library/Package Starter Kit

A minimal template to kickstart your own JavaScript (or TypeScript) library/package.

---

## ✅ Features

This starter kit includes everything you need to build, document, and publish your library:

- ✅ **ES Module** build output for modern bundlers
- ✅ **Bundled global `.d.ts` TypeScript declarations**
- ✅ **Preconfigured Storybook** for developing and previewing UI components
- ✅ Ready for **npm publishing**
- ✅ Clean project structure with example components

---

## 🚀 Getting Started

1. **Clone this repository:**

```bash
git clone git@github.com:datuchaa/template-pkg-with-storybook.git your-library
cd your-library
```
